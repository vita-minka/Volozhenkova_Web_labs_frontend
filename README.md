# Letters Evolution Stages — Frontend (Lab 5)

Базовое SPA на React + TypeScript + Vite для просмотра услуг из mock-объектов. 
Разработано в рамках Лабораторной работы №5.

## Запуск

```bash
npm install
npm run dev
```
Приложение откроется по адресу: **http://localhost:5173/**

## Навигация

Внизу экрана расположена панель навигации из **4 пунктов**:
- **Лента** (доступна) — переход на главную страницу со списком карточек.
- **Добавление** (недоступна) — заглушка.
- **Плитка** (доступна) — переход на страницу сетки карточек с фильтром.
- **Вход** (недоступна) — заглушка.

## Страница 1. «Лента» (`/`)

**Описание:** Страница полноэкранного просмотра одной карточки.
**Элементы:**
- **Медиа-фон:** видео (если `videoUrl` задан) или изображение (если задано `imageUrl`). Если оба поля пустые, подгружается дефолтная картинка `default-image.jpg`.
- **Текст поверх фона:** заголовок и краткое описание услуги.
- **Поля по теме:** два бейджа (например, «Век: 11» и «Признак: Ять»).
- **Лайк:** иконка сердечка с числом.
- **Кнопка «Следующая» (▼):** переключает на следующую карточку из массива. На последней карточке кнопка не работает.

## Страница 2. «Плитка» (`/tile`)

**Описание:** Страница каталога всех услуг в виде сетки.
**Элементы:**
- **Поле фильтрации:** выпадающий список (Select) для выбора века (Все века, XI век, XIV век и т.д.). При выборе значения список карточек мгновенно фильтруется.
- **Сетка карточек:** отображает карточки в 2 колонки.
- **Карточка:** содержит изображение (или дефолтную заглушку, если в моке `imageUrl` пустой), название, лайк и иконку стрелки.
- **Клик по карточке:** переносит пользователя на страницу «Лента» с выбранной карточкой.

## Использование данных

На данном этапе (Лаба 5) данные берутся **исключительно из локального массива** `src/mock/stages.ts` (без запросов к бэкенду). 
Для карточек с пустыми полями `imageUrl` или `videoUrl` предусмотрены изображения и видео по умолчанию из папки `public/`.
