# Letters Evolution Stages — Frontend

> Лабораторная 5: SPA на React + TypeScript + Vite для просмотра каталога этапов эволюции письма.

---

## О проекте

**Frontend-приложение** для веб-сервиса «Letters Evolution Stages». 
Разработано в рамках лабораторной работы №5 по курсу «Разработка интернет-приложений» (МГТУ им. Н.Э. Баумана, кафедра ИУ-5).

Приложение представляет собой **мобильный интерфейс** (фиксированная ширина 390px, как у смартфона) для просмотра двух страниц:
1. **Лента** — полноэкранный просмотр этапа с видео/картинкой на весь экран и наложенным текстом.
2. **Плитка** — сетка карточек этапов с фильтрацией по векам.

**Ключевая особенность лабы 5:** данные берутся **только из mock-объектов** (находятся в `src/mock/stages.ts`). Запросов к бэкенду (NestJS), базе данных (PostgreSQL) или объектному хранилищу (MinIO) на этом этапе нет. Навигационное меню состоит из 4 пунктов, но только 2 из них активны.

## Стек технологий

| Технология | Назначение |
|---|---|
| **React 18** | Библиотека для построения пользовательских интерфейсов на основе компонентов |
| **TypeScript** | Строгая типизация (защита от ошибок на этапе компиляции) |
| **Vite** | Сборщик и dev-сервер (мгновенный запуск и Hot Module Replacement) |
| **React Router DOM** | Клиентский роутинг (переход между страницами без перезагрузки) |
| **React-Bootstrap** | Готовые UI-компоненты (карточки, кнопки, выпадающие списки) |

## Страницы приложения

### 1. Лента (`/`)

Страница для полноэкранного просмотра этапа.

**Элементы страницы:**
- Видеофайл на весь экран (если у объекта в моке пустой `videoUrl`, показывается картинка; если пуст и `imageUrl`, показывается дефолтная картинка).
- Заголовок этапа.
- Текстовое описание.
- Бейджи с параметрами по теме: «Век» и «Признак».
- Счетчик лайков (сердечко).
- Кнопка «Следующая» (стрелка вниз), переключающая на следующий объект из массива.

**Особенности:**
- Используется хук `useState` для хранения текущего индекса карточки.
- Используется `useEffect` для загрузки мок-данных при монтировании компонента.

### 2. Плитка (`/tile`)

Страница со списком всех этапов в виде сетки.

**Элементы страницы:**
- Выпадающий список (Select) для фильтрации по векам (XI век, XIV век и т.д.).
- Сетка карточек в 2 колонки.
- В каждой карточке: картинка (или дефолт), название этапа, количество лайков и стрелка.

**Особенности:**
- Используется хук `useMemo` для быстрой фильтрации массива по выбранному веку без лишних перерисовок.
- Фильтрация происходит «на лету» — при выборе века из списка.

## Нижняя навигационная панель (TabBar)

Компонент `TabBar.tsx` закреплен внизу экрана и содержит 4 пункта согласно заданию:

| Пункт меню | Путь | Статус | Что делает |
|---|---|---|---|
| **Лента** | `/` | 🟢 Активен | Переход на страницу просмотра |
| **Добавление** | `/add` | 🔴 Неактивен | Заглушка (в лабе 5 не реализовано) |
| **Плитка** | `/tile` | 🟢 Активен | Переход на страницу плитки |
| **Вход** | `/login` | 🔴 Неактивен | Заглушка (в лабе 5 не реализовано) |

Неактивные пункты имеют серый цвет и не реагируют на клики (`disabled`), как того требует методичка.

## Работа с мок-данными и дефолтные значения

Все данные для карточек хранятся в файле `src/mock/stages.ts` в виде интерфейса `Stage`.

**Проверка дефолтных изображений:**
- В моке есть объект с `imageUrl: ''` (пустая строка). На плитке для него автоматически подставляется `default-image.jpg` из папки `public/images`.
- В моке есть объект с `videoUrl: ''`. На странице ленты вместо видео для него отобразится картинка (fallback).
- Это реализовано через логические операторы в JSX: `src={stage.imageUrl || DEFAULT_IMAGE}`.

## Используемые хуки React

В проекте задействованы три базовых хука:

1. **`useState`** — для хранения списка этапов (`stages`), текущего индекса (`currentIndex`) и выбранного века для фильтра (`century`).
2. **`useEffect`** — для имитации загрузки данных (установка массива из мока в стейт при первом рендере, с пустым массивом зависимостей `[]`).
3. **`useMemo`** — для оптимизации фильтрации (чтобы массив пересчитывался только при изменении выбранного века или самого массива).
