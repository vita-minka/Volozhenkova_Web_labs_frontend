# Letters Evolution Stages — Frontend

> SPA на React для просмотра каталога этапов эволюции письма

---

## О проекте

**Letters Evolution Stages — Frontend** — клиентская часть (SPA) учебного проекта, разработанного в рамках курса «Разработка интернет-приложений» (МГТУ им. Н.Э. Баумана, кафедра ИУ-5).

Сервис помогает исследователям-палеографам определять **вероятный временной интервал создания рукописи** на основе анализа начертаний букв кириллицы (этапов эволюции: «ять», твёрдый знак «ъ», «фита»).

Данный репозиторий содержит **только Frontend-приложение**. Серверная часть (NestJS + PostgreSQL + MinIO + Redis) находится в отдельном репозитории.

### Текущий этап разработки

В соответствии с заданием лабораторной работы, приложение представляет собой **базовый интерфейс на React для гостя**. На данном этапе:
- Данные берутся **только из mock-объектов** (`src/mock/stages.ts`). Запросов к бэкенду, БД или S3 пока нет.
- Реализованы **две страницы**: «Лента» и «Плитка».
- Нижняя навигационная панель состоит из **4 пунктов**, но 2 из них (Добавление и Вход) неактивны.
- Для вёрстки используются готовые компоненты **React-Bootstrap**.

## Страницы приложения

### 1. Лента (`/`)
- **Что показывает:** Полноэкранное видео (или картинка) с информацией поверх него.
- **Элементы:** Заголовок, описание, два поля по теме (век и признак), лайк, кнопка перехода к следующей карточке (▼).
- **Хуки:** `useState` (индекс карточки), `useEffect` (загрузка мока при старте).

### 2. Плитка (`/tile`)
- **Что показывает:** Сетку карточек в 2 колонки.
- **Элементы:** Выпадающий список (фильтр по веку), карточки с картинками, названиями, лайками и стрелками.
- **Хуки:** `useState` (выбранный век), `useEffect` (загрузка мока), `useMemo` (фильтрация массива).

## Навигационная панель (TabBar)

Панель закреплена снизу и содержит 4 пункта (как требует задание):
- 🟢 **Лента** — активна (переход на `/`)
- 🔴 **Добавление** — неактивна (заглушка)
- 🟢 **Плитка** — активна (переход на `/tile`)
- 🔴 **Вход** — неактивна (заглушка)

## Работа с медиа (Дефолтные значения)

Для всех карточек предусмотрены изображения и видео по умолчанию (в папке `public/`), если в мок-объекте поле пустое:
- Если `imageUrl` пустой → подставляется `public/images/default-image.jpg`.
- Если `videoUrl` пустой → вместо видео отрисовывается изображение.
